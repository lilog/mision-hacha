# Misión Hacha 🪓

Mini web estática para regalar una tarjeta de Decathlon con un juego de encontrar las diferencias.

## Publicar en GitHub Pages

1. Creá un repositorio nuevo en GitHub.
2. Subí `index.html` y la carpeta `assets`.
3. En el repositorio: **Settings → Pages**.
4. En **Build and deployment**, elegí **Deploy from a branch**.
5. Seleccioná `main` y `/ (root)`.
6. Guardá. GitHub mostrará la URL pública cuando termine de publicar.

## Importante
No pongas el código o PIN real de la tarjeta regalo en esta web si el repositorio o GitHub Pages son públicos.

## Personalización rápida
En `index.html` podés cambiar directamente:
- “Tarjeta regalo de Decathlon”
- el mensaje final
- los textos de inicio

Todo funciona sin servidor ni librerías externas.
